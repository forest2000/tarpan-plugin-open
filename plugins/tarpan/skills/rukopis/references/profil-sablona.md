# Šablona stylového profilu

Profil se vyplňuje z 3–5 vzorků vlastních textů uživatele (e-maily, memoranda,
dopisy). Každý oddíl je seznam krátkých, ověřitelných pravidel — co se ve
vzorcích opakuje, ne co by „bylo hezké". Co ze vzorků nejde vyčíst, nech prázdné
a nedomýšlej.

Hotový profil ukaž uživateli a po odsouhlasení ulož do
`~/.claude/tarpan/rukopis.md`.

---

```markdown
# Rukopis — <jméno uživatele>

Vytěženo z: <počet a druh vzorků>, <datum>

## Tón a registr
- formální / neformální / podle adresáta: …
- osoba: já / my (kancelář) / neosobně: …
- vykání / tykání: …

## Struktura
- délka odstavců (typicky … vět): …
- prázdné řádky mezi odstavci: ano / ne
- jedna myšlenka = jeden odstavec: ano / ne
- délka vět (krátké / střední / souvětí): …

## Výčty
- číslování: (i)/(ii)/(iii) · 1./2./3. · a)/b)/c) · odrážky
- výčet v textu nebo pod sebou: …

## Zvýraznění
- tučné / podtržení / kurzíva / nic: …
- k čemu (definice, lhůty, závěr): …

## Oslovení a závěr
- oslovení (přesné znění): „…"
- závěr (přesné znění): „S pozdravem" + …
- podpis (jméno, funkce, kontakt): …

## Předmět e-mailu
- formát: „<věc> — <co>" / „Re: …" / …

## Odkazy na předpisy
- cituje předpisy: ano / ne
- forma: „§ 2048 OZ" / „§ 2048 zákona č. 89/2012 Sb." / …

## Oblíbené obraty
- „…"

## Zakázané obraty
- „…"

## Typografie
- uvozovky: „…" / "…" / »…«
- pomlčky: spojovník / pomlčka – / em-dash — / nepoužívá
- nedělitelné mezery: § 123 · 5 000 Kč · …

## Ukázkový odstavec
> 1–2 věty doslova ze vzorku, které styl nejlépe vystihují.
```
